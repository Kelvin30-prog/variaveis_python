Neste projeto prático, explorei o ciclo de manipulação de dados em um script simples, mas fundamental:

  1. Declaração Inicial: Criei variáveis de diferentes tipos (str, int, float.).
  2. Identificação de Tipo (type()): Confirmei o tipo de cada variável, entendendo a tipagem dinâmica do Python.
  3. Conversão de Tipo (Type Casting): Pratiquei a conversão entre tipos de dados (ex: de str para int), um passo crucial para realizar operações matemáticas após coletar dados via input.
  4. Interação com o Usuário: Usei a função input() para solicitar informações dinâmicas e personalizar a execução do código.

O código finaliza com um print formatado, reunindo informações fornecidas e processadas.

É um excelente exercício para fixar como o Python lida com inputs e como garantir que os dados estejam no formato correto para serem usados!
